Walk through a single scalar Adam timestep exactly as in Algorithm 1: form the first and second moment estimates from a toy prior state and the current gradient, apply bias correction, and compute the parameter update.

  • Compute the first and second moment estimates and their bias-corrected versions for one scalar Adam step.
  • Compute the parameter update and explain how the learning rate, gradient, and prior moments control its sign and magnitude.

Build an intuition

Adam keeps a running average of gradients (first moment) and of squared gradients (second moment). Because both averages start at zero, they are biased toward zero early on; dividing by 1 - beta^t removes that bias. The update then moves the parameter by a step whose size is roughly the learning rate, scaled by the ratio of the corrected mean to the corrected root-mean-square gradient.

Follow the mechanism

  1. First moment estimate: exponential moving average of the gradient, combining the decayed prior moment with the new gradient.
  2. Second moment estimate: exponential moving average of the squared gradient.
  3. Bias-corrected first moment: divides by 1 - beta1^t to remove the zero-initialization bias.
  4. Bias-corrected second moment: divides by 1 - beta2^t to remove the zero-initialization bias.
  5. Parameter update: learning rate times the bias-corrected moment ratio, with epsilon inside the denominator for stability.
  6. New parameter value after subtracting the update, since the gradient points toward increasing loss.

Two ways to explore

Exploration 1

Gradient sign and magnitude

Change: Set g to -0.8; Set alpha to 0.01.

Observe: Calculated results for this setup, compared with the starting inputs: m_t = -0.08 (starting value: 0.04); v_t = 0.00064 (starting value: 0.00016); m_hat_t = -0.8 (starting value: 0.4); v_hat_t = 0.64 (starting value: 0.16); delta_t = -0.0099999999 (starting value: 0.0099999998); theta_t = 0.0099999999 (starting value: -0.0099999998).

Why: The first moment tracks the sign of the gradient, and the update inherits that sign. The second moment grows with the square of the gradient, so the denominator changes more slowly than the numerator, letting a larger gradient produce a larger step.

Exploration 2

Learning rate scaling

Change: Set g to 0.4; Set alpha to 0.05.

Observe: Calculated results for this setup, compared with the starting inputs: m_t = 0.04 (starting value: 0.04); v_t = 0.00016 (starting value: 0.00016); m_hat_t = 0.4 (starting value: 0.4); v_hat_t = 0.16 (starting value: 0.16); delta_t = 0.049999999 (starting value: 0.0099999998); theta_t = -0.049999999 (starting value: -0.0099999998).

Why: The learning rate multiplies the bias-corrected moment ratio directly, so it scales the step without altering the moment estimates or their correction.

Where this demonstration stops

Only one scalar parameter and one timestep are shown; multi-parameter behavior and long-run convergence are out of scope.

Bias correction is not an optional tweak: without dividing by 1 - beta1^t and 1 - beta2^t, the moments are systematically too small early in training, so the first steps would be far smaller than the learning rate suggests.

One scalar parameter, one timestep t >= 1, with explicit toy prior moments m_prev and v_prev. No training loop, no model, no data pipeline. The gradient g is treated as given for this step.

  • Only one scalar parameter and one timestep are shown; multi-parameter behavior and long-run convergence are out of scope.
  • The paper's effective-stepsize bounds and SNR discussion are not reproduced here; this lesson covers the update arithmetic only.
  • The gradient g is supplied for this single step; no backpropagation or loss function is modeled.
  • The prior moments m_prev and v_prev are toy values representing the state after t-1 steps, not learned quantities.
