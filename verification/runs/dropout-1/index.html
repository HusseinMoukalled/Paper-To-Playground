Show how a binary dropout mask zeroes activations during training, and how the paper's test-time convention compensates by scaling weights rather than sampling masks.

  • Compute the training-time masked activation from an activation vector and a binary mask.
  • Distinguish the paper's test-time weight-scaling convention from training-time masking, and label any alternative scaling convention explicitly.

Build an intuition

During training, each unit is kept with probability p and otherwise set to zero, so the expected activation of a kept unit is p times its original value. At test time the paper avoids sampling masks and instead scales the weights down by p, which makes the deterministic test activation match that same expected value.

Two ways to explore

Exploration 1

Mask pattern changes training activations but not test-time scaling

Change: Set m to [0, 1, 0, 1]; Set p to 0.5.

Observe: Calculated results for this setup, compared with the starting inputs: masked training activation = [0.0, -1.0, 0.0, 3.0] (starting value: [2.0, -0.0, 0.5, 3.0]); test-time activation under paper weight scaling = [1.0, -0.5, 0.25, 1.5] (starting value: [1.0, -0.5, 0.25, 1.5]); test-time activation under alternative 1/p scaling = [4.0, -2.0, 1.0, 6.0] (starting value: [4.0, -2.0, 1.0, 6.0]); expected training activation = [1.0, -0.5, 0.25, 1.5] (starting value: [1.0, -0.5, 0.25, 1.5]).

Why: The mask only affects which units are zeroed during training. The test-time scaling depends only on p and the original activations, so it is unchanged by the mask pattern.

Exploration 2

Retention probability changes the test-time scaling factor

Change: Set m to [1, 0, 1, 1]; Set p to 0.8.

Observe: Calculated results for this setup, compared with the starting inputs: masked training activation = [2.0, -0.0, 0.5, 3.0] (starting value: [2.0, -0.0, 0.5, 3.0]); test-time activation under paper weight scaling = [1.6, -0.8, 0.4, 2.4] (starting value: [1.0, -0.5, 0.25, 1.5]); test-time activation under alternative 1/p scaling = [2.5, -1.25, 0.625, 3.75] (starting value: [4.0, -2.0, 1.0, 6.0]); expected training activation = [1.6, -0.8, 0.4, 2.4] (starting value: [1.0, -0.5, 0.25, 1.5]).

Why: Increasing p raises the expected fraction of kept units, so the paper's test-time scaling factor p increases. The training mask is fixed in this exploration, so the masked training activation does not change.

Where this demonstration stops

Only one fixed mask is shown; the paper's training procedure draws a fresh independent mask per example and per unit.

Dropout is not simply deleting units at test time. At test time the paper uses a deterministic scaled network, not a random mask.

A single fixed activation vector with an editable binary mask and retention probability. We compute the masked training activation and the paper's test-time scaled activation. We do not train, sample random masks, or evaluate Monte-Carlo model averaging.

  • Only one fixed mask is shown; the paper's training procedure draws a fresh independent mask per example and per unit.
  • The test-time scaling is applied here directly to activations for comparison; in the paper it is applied to the weights of the trained network.
  • The activation vector is a fixed illustrative example, not a random sample.
  • The mask is a fixed binary pattern used to illustrate one training step; it is not drawn at random.
