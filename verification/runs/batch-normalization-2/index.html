Walk through the Batch Normalization transform of Algorithm 1 on a small scalar minibatch: compute the batch mean, the batch variance, the normalized values, and the affine output, and see how the affine scale and shift and the stabilizer epsilon change the result.

  • Compute the batch mean and batch variance of a scalar minibatch and use them to produce normalized values.
  • Explain how the affine scale, affine shift, and stabilizer epsilon change the normalized and affine outputs.

Build an intuition

Batch Normalization re-centers each minibatch by subtracting its mean and re-scales it by its standard deviation, so the normalized values have roughly zero mean and unit variance. A learned scale and shift then let the layer recover any representation it needs, so normalization does not remove expressive power.

The parts and symbols

minibatch activations x
The four scalar activations of one feature in the current minibatch, before normalization. SOURCE_GROUNDED
affine scale gamma
The learned scale applied to each normalized value; it lets the layer undo or reshape the normalization. SOURCE_GROUNDED
affine shift beta
The learned shift added after scaling; it lets the layer set the output mean. SOURCE_GROUNDED
stabilizer epsilon
A small positive constant added to the batch variance before the square root, so the denominator never becomes zero. SOURCE_GROUNDED
batch mean mu
The arithmetic mean of the minibatch activations, the center that is subtracted from every activation. DERIVED
centered activations x - mu
Each activation with the batch mean removed, so the centered minibatch has zero mean. DERIVED
batch variance sigma squared
The population variance of the minibatch, the mean of the squared centered activations. DERIVED
sqrt(variance + epsilon)
The standard deviation of the minibatch with the stabilizer epsilon added inside the square root, used as the normalizing divisor. DERIVED
normalized values x hat
The centered activations divided by the stabilized standard deviation, giving the normalized minibatch. DERIVED
affine output y
The normalized values scaled by gamma and shifted by beta, the output of the Batch Normalization transform. DERIVED

Follow the mechanism

  1. The arithmetic mean of the minibatch activations, the center that is subtracted from every activation.
  2. Each activation with the batch mean removed, so the centered minibatch has zero mean.
  3. The population variance of the minibatch, the mean of the squared centered activations.
  4. The standard deviation of the minibatch with the stabilizer epsilon added inside the square root, used as the normalizing divisor.
  5. The centered activations divided by the stabilized standard deviation, giving the normalized minibatch.
  6. The normalized values scaled by gamma and shifted by beta, the output of the Batch Normalization transform.

Two ways to explore

Exploration 1

Constant minibatch: epsilon is the only stabilizer

Change: Set minibatch activations x to [2.0, 2.0, 2.0, 2.0]; Set affine scale gamma to 1.0; Set affine shift beta to 0.0; Set stabilizer epsilon to 0.001.

Observe: Calculated results for this setup, compared with the starting inputs: batch mean mu = 2.0 (starting value: 2.5); centered activations x - mu = [0.0, 0.0, 0.0, 0.0] (starting value: [-1.5, -0.5, 0.5, 1.5]); batch variance sigma squared = 0.0 (starting value: 1.25); sqrt(variance + epsilon) = 0.031622777 (starting value: 1.1184811); normalized values x hat = [0.0, 0.0, 0.0, 0.0] (starting value: [-1.3411045, -0.44703482, 0.44703482, 1.3411045]); affine output y = [0.0, 0.0, 0.0, 0.0] (starting value: [-1.3411045, -0.44703482, 0.44703482, 1.3411045]).

Why: With a constant minibatch the centered activations are all zero, so the variance is zero and the square root would be zero without epsilon. The stabilizer keeps the denominator positive, and the normalized values collapse to zero because there is no spread to rescale.

Exploration 2

Affine scale and shift reshape the normalized output

Change: Set minibatch activations x to [1.0, 2.0, 3.0, 4.0]; Set affine scale gamma to 2.0; Set affine shift beta to 1.0; Set stabilizer epsilon to 0.001.

Observe: Calculated results for this setup, compared with the starting inputs: batch mean mu = 2.5 (starting value: 2.5); centered activations x - mu = [-1.5, -0.5, 0.5, 1.5] (starting value: [-1.5, -0.5, 0.5, 1.5]); batch variance sigma squared = 1.25 (starting value: 1.25); sqrt(variance + epsilon) = 1.1184811 (starting value: 1.1184811); normalized values x hat = [-1.3411045, -0.44703482, 0.44703482, 1.3411045] (starting value: [-1.3411045, -0.44703482, 0.44703482, 1.3411045]); affine output y = [-1.6822089, 0.10593037, 1.8940696, 3.6822089] (starting value: [-1.3411045, -0.44703482, 0.44703482, 1.3411045]).

Why: The affine parameters act after normalization, so they do not change the batch statistics or the normalized values. Scaling by gamma stretches the normalized spread and shifting by beta moves the output mean, which is why normalization does not restrict what the layer can represent.

Where this demonstration stops

Only one forward pass is shown; the running averages used at inference time and the gradient updates of the affine parameters are not modeled.

Normalization does not force the layer output to have zero mean and unit variance: the affine scale and shift are applied after normalization and can move and stretch the output anywhere.

A single scalar feature over a fixed-size minibatch of four examples, evaluated in one forward pass. Only the normalization and affine transform are shown; no network layers, no loss, no backpropagation, and no training are performed.

  • Only one forward pass is shown; the running averages used at inference time and the gradient updates of the affine parameters are not modeled.
  • The minibatch is tiny and fixed in size, so the statistics are noisy and do not represent the training-set distribution.
  • The minibatch has four scalar activations for one feature; the same formula applies independently to each feature.
  • The variance is the biased (population) variance over the minibatch, matching the normalization step of Algorithm 1.
