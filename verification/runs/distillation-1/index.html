Explain how a teacher's logits are turned into soft targets by a temperature-scaled softmax, how the student's soft-target cross-entropy is computed, and why the soft-loss term is multiplied by T² when combined with a hard-label loss.

  • Compute teacher and student softmax distributions at a chosen temperature T and interpret how T controls their sharpness.
  • Compute the soft-target cross-entropy H(p_T, q_T) and the T²-scaled combination with a hard-label cross-entropy.

Build an intuition

A high softmax temperature flattens the teacher's distribution, exposing relative preferences among non-target classes that a hard label hides. The student is trained to match this soft distribution. Because raising T shrinks the soft-loss gradients by roughly 1/T², the soft term is multiplied by T² so that its influence relative to the hard-label term stays comparable when T is changed.

Follow the mechanism

  1. Teacher logits divided by T, then softmaxed, giving the soft target distribution p_i = e^{v_i/T} / Σ_j e^{v_j/T}.
  2. Student logits divided by the same T, then softmaxed, giving q_i = e^{z_i/T} / Σ_j e^{z_j/T}.
  3. Soft-target cross-entropy H(p,q) = -Σ_i p_i ln q_i in nats, computed at the same temperature T used to make the soft targets.
  4. The same student logits softmaxed at temperature 1, as used for the hard-label cross-entropy.
  5. Hard-label cross-entropy H(y, q^(1)) = -Σ_i y_i ln q_i^(1) in nats, computed at temperature 1.
  6. Weighted combination: the soft-target cross-entropy is multiplied by T² to compensate the 1/T² gradient scaling, and the hard-label cross-entropy is weighted by α.

Two ways to explore

Exploration 1

Low temperature sharpens the soft targets

Change: Set T to 1.0.

Observe: Calculated results for this setup, compared with the starting inputs: p (teacher soft targets) = [0.86681333, 0.11731043, 0.01587624] (starting value: [0.66524096, 0.24472847, 0.090030573]); q (student soft predictions) = [0.73612472, 0.16425163, 0.099623648] (starting value: [0.54340561, 0.25668664, 0.19990775]); H(p, q) = 0.51407383 nats (starting value: 0.88347618 nats); q^(1) (student at T = 1) = [0.73612472, 0.16425163, 0.099623648] (starting value: [0.73612472, 0.16425163, 0.099623648]); H(y, q^(1)) = 0.30635571 nats (starting value: 0.30635571 nats); L = 0.60598055 nats (starting value: 3.6258114 nats).

Why: Dividing logits by a smaller T preserves larger gaps between logits, so the softmax is sharper; the soft cross-entropy then depends mostly on the top class, and the T² rescaling is inactive.

Exploration 2

High temperature softens the targets and amplifies the soft term

Change: Set T to 6.0.

Observe: Calculated results for this setup, compared with the starting inputs: p (teacher soft targets) = [0.44844086, 0.32132192, 0.23023722] (starting value: [0.66524096, 0.24472847, 0.090030573]); q (student soft predictions) = [0.40074826, 0.31210306, 0.28714868] (starting value: [0.54340561, 0.25668664, 0.19990775]); H(p, q) = 1.071498 nats (starting value: 0.88347618 nats); q^(1) (student at T = 1) = [0.73612472, 0.16425163, 0.099623648] (starting value: [0.73612472, 0.16425163, 0.099623648]); H(y, q^(1)) = 0.30635571 nats (starting value: 0.30635571 nats); L = 38.665836 nats (starting value: 3.6258114 nats).

Why: Dividing logits by a large T compresses their differences, so softmax approaches uniform and the soft targets carry less class-specific signal; the T² factor grows quadratically, compensating the 1/T² gradient scaling so the soft term's relative influence stays comparable when T is tuned.

Where this demonstration stops

We compute the loss components, not the gradients dC/dz_i; the 1/T² gradient scaling is cited but not derived here.

That temperature changes the teacher's knowledge or the class ranking. Temperature only rescales logits before softmax; it changes the sharpness of the distribution, not the ordering of classes.

A single transfer case with small fixed teacher and student logit vectors. We compute the temperature-scaled softmax distributions, the soft-target cross-entropy component, and the T²-scaled combination with a hard-label cross-entropy. No model training, no gradient derivation, no multi-example averaging.

  • We compute the loss components, not the gradients dC/dz_i; the 1/T² gradient scaling is cited but not derived here.
  • The T² factor is applied as a fixed multiplier on the soft cross-entropy term; the paper's argument is about gradient magnitudes, and we do not re-derive it from the gradient expression.
  • One transfer case is shown; the paper averages such per-case losses over the transfer set.
  • The hard-label distribution is a one-hot vector over the same class index used for the teacher's target class.
