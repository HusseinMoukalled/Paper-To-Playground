Gain and offset in an affine response

This original synthetic verification document describes an ideal affine response, not a published experiment. The mechanism is scaling an input followed by adding an offset.

y = a*x + b (1)

The scalar input is x, the gain is a, the offset is b, and the output is y. Increasing a scales the input contribution. Increasing b translates the output. All quantities in this example are dimensionless.

For this teaching example the input may be fixed at x = 2 while gain and offset vary independently. For gain a = 1 and offset b = 0 the result is y = 2; for a = 2 and b = 1 it is y = 5. These are algebraic examples, not measurements.

Assumptions and scope

The ideal model does not represent noise, saturation, dynamics, or experimental performance. Gain and offset are different operations; gain sensitivity disappears when the fixed input is zero. Two nonzero-input setups can contrast scaling and translation.
